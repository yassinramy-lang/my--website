# بورتفوليو مطور ويب وأمن مواقع

## التشغيل
افتح `index.html` في متصفح حديث. يُفضّل استخدام VS Code مع إضافة Live Server للتطوير.

## التخصيص قبل النشر
- تم تخصيص الاسم إلى ياسين رامي. لتغيير الاسم لاحقًا، ابحث عن `ياسين رامي` داخل `index.html`.
- لإضافة صورتك الشخصية، ضع صورة داخل نفس مجلد `index.html` وسمّها `profile.jpg` (يفضّل صورة مربعة). إذا لم تضف الصورة، سيظهر اختصار YR بدلًا منها.
- البريد ما زال تجريبيًا (`your.email@example.com`)؛ استبدله ببريد مناسب قبل النشر العام في `index.html` و`script.js`.
- غيّر روابط GitHub وLinkedIn إلى حساباتك.
- استبدل أمثلة المشاريع بمشاريعك الحقيقية، أو اتركها موسومة بوضوح بأنها تجريبية.
- الخط يُحمّل من Google Fonts؛ إذا أردت العمل دون إنترنت، احذف روابط Google Fonts من `index.html` وسيستخدم المتصفح الخط البديل.

الموقع ثابت ولا يحتاج إلى خادم خلفي. نموذج التواصل غير موجود؛ زر البريد يفتح تطبيق البريد الافتراضي.
